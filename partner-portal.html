Connect Microsoft to start recording sign-ins, form opens and completed submissions. It takes one SharePoint list and three Power Automate flows. The full click-by-click guide is in access-log-setup-microsoft.txt.

  1. Create a SharePoint list Portal Activity with columns Event, PartnerId, Partner, Form.
  2. Flow 1 (write): HTTP request received → Create item. Paste its URL below.
  3. Flow 2 (read): HTTP request received → check key → Get items → Response. Paste its URL and your key below.
  4. Flow 3 (submissions): one per Microsoft Form → Create item with Event "Submitted form".

How to publish changes

  1. Make your changes here.
  2. Click Download partners.json.
  3. In GitHub, open your AbleLiving-training repository, choose Add file → Upload files, and upload it. It replaces the old one.
  4. Changes go live in about a minute.
